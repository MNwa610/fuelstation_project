# HTTP API

Базовый префикс: `/api/v1`. Тела запросов и ответов — JSON. Ошибка: поле `error` и код HTTP.

Роли: публичный доступ, любой вошедший пользователь (Bearer JWT), только ADMIN.

Заголовок авторизации: `Authorization: Bearer <token>`.

## Служебные

### GET /health

Роль: все. Проверка, что процесс сервера жив.

Ответ: `{ "status": "ok" }`

## Авторизация

### POST /api/v1/auth/register

Роль: все.

Запрос:

```
{ "email": "ivan@mail.ru", "password": "123456", "fullName": "Иван Иванов" }
```

Ответ 201: пользователь без passwordHash, роль USER.

Ошибки: 400 валидация, 409 email занят.

### POST /api/v1/auth/login

Роль: все.

Запрос:

```
{ "email": "admin@gazprom.ru", "password": "admin123" }
```

Ответ 200:

```
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": { "id": "...", "email": "admin@gazprom.ru", "fullName": "Администратор", "role": "ADMIN" }
}
```

Ошибка 401 — неверный логин или пароль.

### GET /api/v1/auth/me

Роль: вошедший пользователь.

Ответ 200 — текущий пользователь без хеша пароля. Ошибки: 401 нет или битый токен.

Роль: все. Запрос без тела.

Ответ 200 — одна АЗС в том же виде. 404 — нет такой записи.

## Топливо на АЗС

### PATCH /api/v1/station-fuels/:id

Роль: ADMIN.

Запрос (можно передать часть полей):

```
{ "currentLiters": 500, "price": 56.7, "status": "LOW" }
```

Если переданы литры, статус на сервере пересчитывается по ёмкости и может не совпасть с присланным.

Ответ 200 — обновлённая позиция топлива.

Побочный эффект: создаётся FuelEvent с типом MANUAL, oldLiters, newLiters, comment = id администратора.

Ошибки: 401 без токена, 403 не ADMIN, 404 нет записи, 400 пустое тело или неверные числа.

### GET /api/v1/station-fuels/:id/events

Роль: все. Запрос без тела.

Ответ 200 — массив событий, новые сверху:

```
[
  {
    "id": "...",
    "eventType": "MANUAL",
    "oldLiters": 8000,
    "newLiters": 500,
    "comment": "uuid-администратора",
    "createdAt": "2026-10-28T00:00:00.000Z"
  }
]
```

404 — нет такой позиции топлива.

## Симуляция

### POST /api/v1/simulation/run

Роль: ADMIN. Тело не требуется.

Ответ 200: `{ "updated": 30 }` (число обработанных позиций).

Ошибки: 401, 403.

Дополнительно симуляция вызывается планировщиком раз в сутки (полночь по времени контейнера).
